Music Assistant, redesigned in the spirit of Roon

Editorial serif headlines, big art-led heroes with blurred colour wash, a quiet charcoal (or paper-white) canvas, one violet accent, and a single bottom transport bar with the player picker. Every screen is drawn in both themes from the same token set. Album art is generated placeholders.

Tokens

Drop-in values for the existing shadcn variables in src/styles/style.css; the Vuetify theme in src/plugins should take the same values so both component sets agree.

Type

Newsreader (display serif, stand-in for Roon's Grifo) for page titles, album/artist/track names in heroes and the transport bar, section headings and big numerals. Inter for everything functional: nav, metadata, buttons, tables.

Colour

Neutral greys with a faint cool cast; colour comes from the artwork, not the chrome. One accent (violet) marks the active nav item, the playing row, the selected player and primary actions — nothing else.

Shape

Square-ish album art (4px radius), pills for actions and chips, 8px rows. No cards-with-borders on browse pages: content sits directly on the canvas, separated by whitespace and hairlines.

Music Assistant specifics

Provider choice per album ("Available from"), quality/signal dot, players & groups popover with per-member volume, and the existing Radio / Podcasts / Audiobooks / Browse sections all keep a home in the new shell.
